# АО «НОВЭЛ» — редизайн главной страницы

Редизайн сайта завода теплового, сварочного и взрывозащищённого оборудования
[zaonovel.ru](https://zaonovel.ru/) по референсу 2 (`refs/2.jpg`, ASC Technology Solutions).

Сайт без сборки: чистый HTML + CSS + ванильный JS. Достаточно открыть `index.html`
в браузере — или поднять любой статичный сервер из корня проекта.

## Что внутри

| Файл | Назначение |
|---|---|
| `index.html` | главная страница: герой → цифры завода → три направления → благодарности → финал + подвал; модалка заявки и просмотр писем |
| `assets/css/index.css` | вся визуальная система главной: токены, сетки, типографика, адаптив |
| `assets/js/home.js` | модальное окно заявки, лайтбокс благодарственных писем, Esc, возврат фокуса |
| `assets/img/real/` | реальные материалы с сайта завода: фото производства, логотипы партнёров, сканы писем |
| `DESIGN.md` | дизайн-система: токены, шкала типографики, карта секций, правила контента |
| `docs/screenshots/` | рендеры страницы (десктоп, ноутбук, мобильный) и сравнение с референсом |
| `refs/` | референс и сгенерированные изображения оборудования |
| `about.html`, `calc.html` | внутренние страницы (о заводе, калькулятор) — отдельный набор стилей |

## Структура главной

1. **/ 01 Hero** — «Тепло. Сварка. Взрывозащита.»: российский производитель, завод в Миассе
   (Челябинская область) с 1989 года, взрыв-схема калорифера, логотипы партнёров.
2. **/ 02 Завод в цифрах** — 4 000+ контрагентов · 121 город · 8 стран · 40 видов оборудования;
   фото как фоновая заливка чёрной полосы.
3. **/ 03 Продукция** — тепловое, сварочное и взрывозащищённое оборудование на реальных фотографиях цеха.
4. **/ 04 Благодарности** — благодарственные письма партнёров, оригинал открывается в лайтбоксе.
5. **/ 05 Реальный эффект** — финальный сплит с алой панелью и подвалом.

## Контент

Все цифры, названия продуктов, контакты и сканы писем взяты с
[zaonovel.ru](https://zaonovel.ru/). Метрики вида «99.9% надёжности» или «250+ предприятий»
не используются — только подтверждённые данные завода.

## Проверено

- Chrome 1472 / 1440 / 1920 / 500 px — горизонтального переполнения нет;
- модалка заявки и лайтбокс: открытие, закрытие, Esc, возврат фокуса;
- HTML сбалансирован, кириллица в UTF-8, без ошибок JS.
